# Release 1.24.0

## Scope

This minor release includes `search_project`, a bounded, read-only lexical search of the pinned local repository. The tool returns matching file paths, line numbers, and short excerpts, subject to the existing protected-path policy.

## Validation before release

- `npm test`: 1,133 total; 1,114 passed, 0 failed, 19 skipped.
- `npm run lint`: 263 JavaScript source files checked.
- `npm run check`: entrypoint syntax passed.
- `npm run verify:bundle`: MCP initialized, listed `search_project`, and returned an isolated path:line citation.
- `git diff --check`: passed.
